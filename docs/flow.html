How the whole system sails

From chart to order — every step guarded, every decision logged.

1

Signal

Indikator & cBots ser setupen — prisaction, valutastyrka, gaps eller trendlinjer.

2

44 filter

The validation server scores every signal through 44 rule blocks — session, trend, strength, PSAR, risk.

3

AI-port

An AI model makes the final call — ALLOW or BLOCK — with SL & TP calculated. Auto-fallback keeps it online.

4

Exekvering

The cBot opens the trade with SL/TP already set — one position per pair, spread and session guarded.

5

Kontroll

TradeControl Dashboard watches live PnL — break-even, close commands and Telegram alerts.

Every decision is logged — what came in, what it passed, what the AI decided. You can watch your system think.

Valfritt, aldrig krav

Each step also works standalone. Running just GapTrader without a server? Fine. Running the full ecosystem? Every signal is guarded all the way. The flow is an enhancement, not a dependency.

Fallback genom hela kedjan

The AI gate has provider fallback (glm → groq → kimi). The server has openclaw_fallback=configurable. The cBot has a ReadFromServer guard. If one link goes down, the next takes over — or the trade is blocked safely.

Full traceability

The trade_checks table logs every signal: which of the 44 blocks it passed/failed, the AI's confidence, response time. The dashboard's "Trade Check Analytics" gives win-rate per block — you can see which rules actually protect you.

Two modes, one philosophy

Standalone cBot = lines, levels, price. ZaliMatrix = 44 filters + AI context. Same philosophy in both: no trade without a protocol saying yes — the protocol is just bigger in the ecosystem.
